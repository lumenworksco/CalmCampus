# Security Policy

CalmCampus handles sensitive wellbeing data, so privacy and security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead: go to the [Security tab](https://github.com/lumenworksco/CalmCampus/security/advisories/new) and choose *Report a vulnerability*.

Include what you found, how to reproduce it, and the impact. You can expect an initial response within a week.

## Scope

In scope: the code in this repository, including anything that could cause user data to leave the device, and weaknesses in how the on-device model's safety path is used.

The project is pre-release, so there are no supported versions yet; fixes land on `main`.

## Crisis resources

This repository is not a crisis service. If you or someone else is in danger, contact your local emergency number.
